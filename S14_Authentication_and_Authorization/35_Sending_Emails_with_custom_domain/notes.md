- To send emails with custom domain, for that we need to have a domain and then we can use resend.com as they provide the smtp service to send domains using custom domain.
- We need to connect our domain with resend.com and they will provide us the api key which we can use.
- To send emails using resend, we use resend npm package and for that they provide the code as well, to send emails.

* Resend supports email sending and receiving with custom domains at Free tier with 100msg/day and 3000msg/month.
  It's an amazing SAAS for beginner like us.
